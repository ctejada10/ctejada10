### Hola! 👋

I'm a postdoctoral fellow at the University of Washington. I work on making
computer-aided design (CAD) software accessible to blind and low-vision people,
as part of the [CAD Accessibility](https://github.com/cad-accessibility)
project.

I hold a PhD in Computer Science (Human-Computer Interaction) from the
University of Copenhagen. My dissertation introduced Print-and-Play
Fabrication: interactive objects that come off the 3D printer ready to use,
with little or no assembly. You can read it
[here](https://github.com/ctejada10/print-and-play/blob/master/print-and-play.pdf).

Some of that work, with code and models:

- [AirLogic](https://github.com/ctejada10/airlogic): pneumatic computation and
  I/O embedded in 3D-printed objects, with no electronics.
- [AirTouch](https://github.com/ctejada10/airtouch): touch-sensitive
  3D-printed objects using pneumatic sensing.
- [EchoTube](https://github.com/ctejada10/echotube): touch sensing along
  flexible tubes using waveguided ultrasound.

Before UW, I was a postdoctoral fellow at Aarhus University.
